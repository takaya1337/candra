# sacred_time

Candra's calendar and astronomy engine: weton, the Javanese, Hijri and
Chinese calendars, the sun, the moon, positions in the sky, prayer times,
bazi and the pranata mangsa. It is pure Dart, with no Flutter and no
runtime dependencies. Each file names the works it rests on, and the
tests check it against published tables.

- Run the tests: `dart test`
- The generator scripts in `tool/` are run by hand, never by the app.
